PHASE 3 — Build the Insights / Article System
We need to be able to publish articles easily without redesigning the website every time.
Create one sample article.
Every article should automatically have:
Article Title

Published: [date]
Last Updated: [date]
Article content
Sources / References
Related Articles
The author’s name should be clickable and lead to Sharon’s profile page.
Every article must have its own URL.
Example:
/insights/retirement/retirement-income-planning
Important
Do not manually build a completely new webpage every time we publish an article.
Create a reusable article template.
Phase 3 Deliverable
Publish ONE test article using dummy text so we can test the system.

PHASE 4 — Prepare English + Chinese Capability
The website should eventually support both English and Chinese.
Do NOT put the full English article and Chinese article together on one long webpage.
Prepare separate URLs.
Example:
English:
/insights/retirement/retirement-income-planning
Chinese:
/zh/insights/retirement/retirement-income-planning
Add:
English | 中文
near the top of the page when both versions exist.
We do not need to translate the whole website yet.
For now, simply make sure the website architecture can support this later.
Phase 4 Deliverable
Create one English test page and one Chinese test page and show how users switch between them.
STOP HERE FOR REVIEW.

PHASE 7 — Basic Search Setup
Once the website structure works, complete the basic technical setup.
Make sure the site has:
HTTPS
robots.txt
XML sitemap
Google indexing capability
Bing indexing capability
OAI-SearchBot access
clean URLs
unique page titles
meta descriptions
canonical URLs
proper H1, H2 and H3 headings
mobile-friendly pages
fast loading
alt text capability for images
Important text should be actual HTML text, not text embedded inside images.
Phase 7 Deliverable
Give Mom the URLs for:
robots.txt
XML sitemap
Google Search Console
Bing Webmaster Tools
